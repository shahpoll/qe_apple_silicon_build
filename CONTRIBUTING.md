# Contributing

Use the curl/source installation path and existing native tools. Do not provision or update shared dependencies automatically. Run `python3 -B -m unittest discover -s tests -v` for harness changes, then the affected real numerical cases on an identified inactive suite.

Keep baseline defect evidence, negative controls, valid controls, real integration logs, and review status. Every attempt needs a new external directory. Never alter references, exclude required coverage, substitute serial execution, or loosen a tolerance solely to make a candidate pass. Model/UPF/mesh/cutoff changes are explicit variants.

Scientific claims must list exact inputs, hashes, units, backend, platform, actual ranks, numerical limits, and coverage. Build presence, launch, execution, convergence, numerical agreement, and production-model adequacy are distinct. Publication and comprehensive activation require reviewed complete evidence.

The hosted `Checks` workflow runs tooling and bootstrap regression tests on macOS. Full QE numerical CI is a separate manually dispatched workflow on prepared hardware; a green tooling badge is not physical qualification. Source/build logs from maintainer devices belong outside the repository.
